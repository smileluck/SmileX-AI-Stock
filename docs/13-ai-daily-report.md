# AI 每日收盘报告 PRD

## 1. 模块概述

| 属性 | 值 |
|---|---|
| 模块 ID | 13 |
| 模块名称 | AI 每日收盘报告 |
| 核心功能 | 综合大盘/板块/资金/新闻的每日收盘 AI 报告 |
| 关键文件 | `backend/app/services/ai_daily_report.py` |
| 触发方式 | 定时任务 + REST API |

## 2. 报告内容

### 2.1 大盘综述

- 当日市场总体表现
- 主要指数涨跌幅
- 市场情绪判断

### 2.2 板块热点

- 当日涨幅最大的板块
- 资金流入最多的板块
- 板块轮动分析

### 2.3 资金流向

- 北向资金（港资）动向
- 主力资金净流入/净流出
- 融资融券变化

### 2.4 新闻情绪

- 当日重要新闻摘要
- 新闻对市场的影响分析
- 情绪指数

### 2.5 明日展望

- AI 对次日走势的判断
- 需要关注的事件
- 操作建议

### 2.6 风险提示

- 需要注意的风险因素
- 可能的大幅波动预警

## 3. 定时任务

| 任务 ID | 时间 | 说明 |
|---|---|---|
| `ai_daily_report` | 15:25（工作日） | AI 综合收盘报告 |

## 4. API 端点

- `GET /api/v1/ai-daily-report` — AI 每日收盘报告
