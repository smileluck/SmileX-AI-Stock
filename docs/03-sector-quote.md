# 板块行情快照 PRD

## 1. 模块概述

| 属性 | 值 |
|---|---|
| 模块 ID | 03 |
| 模块名称 | 板块行情快照 |
| 核心功能 | 行业/概念板块实时行情、资金流向、涨跌家数、领涨股 |
| 关键文件 | `backend/app/services/sector.py` |
| 触发方式 | 定时任务 + REST API |

## 2. 功能详情

### 2.1 板块类型

- **行业板块**：按上市公司所属行业分类
- **概念板块**：按题材、概念分类（如新能源、人工智能等）

### 2.2 数据字段

- 板块名称、代码
- 涨跌幅、上涨/下跌家数
- 主力净流入金额
- 领涨股列表
- 板块成交量、成交额

### 2.3 API 端点

- `GET /api/v1/sector` — 实时板块行情
- `GET /api/v1/sector/history` — 板块历史数据

## 3. 定时任务

| 任务 ID | 时间 | 说明 |
|---|---|---|
| `sector_snapshot_midday` | 12:02（工作日） | 午间板块快照 |
| `sector_snapshot_close` | 15:20（工作日） | 收盘板块快照 |

## 4. 数据表

- `sector_snapshot` — 板块快照表
- `sector_daily` — 板块日线表

## 5. 前端页面

- `/sector/today` — 板块总览
- `/sector/history` — 板块历史
