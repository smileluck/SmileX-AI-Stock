# 大盘 AI 分析 PRD

## 1. 模块概述

| 属性 | 值 |
|---|---|
| 模块 ID | 02 |
| 模块名称 | 大盘 AI 分析 |
| 核心功能 | 每日收盘 AI 大盘分析 + 次日指数预测 + 复盘评分 |
| 关键文件 | `backend/app/services/market_analysis.py` |
| 触发方式 | 定时任务 + REST API |

## 2. 功能详情

### 2.1 AI 分析内容

- **大盘综述**：当日市场总体表现
- **板块热点**：当日涨幅/跌幅最大的板块
- **资金流向**：北向资金、主力净流入情况
- **新闻情绪**：当日重要新闻对市场的影响
- **明日展望**：AI 对次日走势的判断
- **风险提示**：需要注意的风险因素

### 2.2 次日预测

- 指数方向（上涨/震荡/下跌）
- 支撑位与阻力位
- 置信度

### 2.3 复盘评分

- 预测准确性回顾
- 胜率统计

## 3. 定时任务

| 任务 ID | 时间 | 说明 |
|---|---|---|
| `daily_market_analysis` | 15:15（工作日） | 指数分析 + 次日预测 |
