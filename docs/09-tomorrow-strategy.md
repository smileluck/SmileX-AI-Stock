# 明日策略 PRD

## 1. 模块概述

| 属性 | 值 |
|---|---|
| 模块 ID | 09 |
| 模块名称 | 明日策略 |
| 核心功能 | 基于板块强度、新闻热度、资金流向的明日板块与个股策略输出 |
| 关键文件 | `backend/app/services/tomorrow_strategy.py` |
| 触发方式 | 定时任务 + REST API |

## 2. 功能详情

### 2.1 输入数据

- 板块连续强势天数（来自 `sector_strength.py`）
- 当日新闻热度（来自 `news_sector_assoc.py`）
- 资金流向（主力净流入）
- 大盘情绪

### 2.2 输出内容

#### 明日 TOP5 板块预测

| 字段 | 说明 |
|---|---|
| sector_name | 板块名称 |
| direction | 方向（强势/轮动/回调） |
| confidence | 置信度（0-100%） |
| drive_factor | 驱动因素 |
| risk_level | 风险等级（低/中/高） |

#### 代表个股

| 类型 | 说明 |
|---|---|
| 领涨龙头 | 板块内最具代表性的个股 |
| 补涨标的 | 可能补涨的个股 |

#### 仓位建议

- 总体仓位（轻仓/半仓/重仓）
- 风格建议（激进/稳健/保守）

### 2.3 策略类型

- 强势延续策略
- 轮动切换策略
- 超跌反弹策略
