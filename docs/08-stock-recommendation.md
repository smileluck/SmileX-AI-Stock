# AI 个股推荐 PRD

## 1. 模块概述

| 属性 | 值 |
|---|---|
| 模块 ID | 08 |
| 模块名称 | AI 个股推荐 |
| 核心功能 | 早盘/午盘/尾盘三档 AI 推荐（规则过滤 + LLM 评分），含买入/止损/目标价 |
| 关键文件 | `backend/app/services/stock.py` |
| 触发方式 | 定时任务 + REST API |

## 2. 功能详情

### 2.1 推荐流程

```
1. 规则初筛 → 候选股池
2. 候选股排序（多维度评分）
3. LLM 五维度评分
4. 输出推荐（含目标价/止损价）
```

### 2.2 初筛规则

- 涨幅区间：1% ~ 8%
- 换手率：≥ 3%
- PE：≤ 50
- 连板数：≤ 3
- 累计涨幅：≤ 20%

### 2.3 LLM 五维度评分

| 维度 | 权重 | 说明 |
|---|---|---|
| 基本面 | 30% | 业绩、估值、成长性 |
| 技术面 | 25% | 趋势、形态、指标 |
| 资金面 | 25% | 主力净流入、换手率 |
| 消息面 | 10% | 利好因素、题材热度 |
| 情绪面 | 10% | 市场情绪、板块联动 |

### 2.4 推荐输出

- 股票代码、名称
- 推荐买入价
- 目标价
- 止损价
- 持仓建议
- 推荐理由

### 2.5 复盘

- 推荐个股次日表现
- 胜率统计

## 3. 定时任务

| 任务 ID | 时间 | 说明 |
|---|---|---|
| `stock_recommendation_morning` | 09:26（工作日） | 早盘AI个股推荐 |
| `stock_recommendation_midday` | 11:25（工作日） | 午盘AI个股推荐 |
| `stock_recommendation_afternoon` | 14:45（工作日） | 尾盘AI个股推荐（主力净流入口径，非涨停） |
| `stock_recommendation_review` | 15:35（工作日） | 收盘复盘推荐 |

## 4. API 端点

- `GET /api/v1/stock/recommendation` — AI 个股推荐
- `GET /api/v1/stock/recommendation/history` — 历史推荐

## 5. 前端页面

- `/stock/recommendation` — AI 个股推荐
- `/stock/history` — 历史推荐
