# 板块 AI 分析 PRD

## 1. 模块概述

| 属性 | 值 |
|---|---|
| 模块 ID | 04 |
| 模块名称 | 板块 AI 分析 |
| 核心功能 | 板块深度 AI 分析（热门/冷门/资金/轮动）+ 明日活跃板块预测 + 复盘 |
| 关键文件 | `backend/app/services/sector_analysis.py` |
| 触发方式 | 定时任务 + REST API |

## 2. 功能详情

### 2.1 AI 分析内容

- **热门板块**：当日资金追捧的板块
- **冷门板块**：当日表现较弱的板块
- **资金流向分析**：主力资金在各板块的流向
- **板块轮动分析**：板块轮动规律与趋势
- **明日活跃板块预测**：
  - 预测方向（活跃/轮动/回调）
  - 置信度
  - 驱动因素
  - 风险等级

### 2.2 周日总结

- 本周板块表现总结
- 下周展望

### 2.3 预测复盘

- 历史预测准确率
- 复盘评分
