# 大盘/指数行情 PRD

## 1. 模块概述

| 属性 | 值 |
|---|---|
| 模块 ID | 01 |
| 模块名称 | 大盘/指数行情 |
| 核心功能 | A股主要指数（上证/深证/创业板/科创50/沪深300等）实时行情快照与历史数据 |
| 关键文件 | `backend/app/services/market.py` |
| 触发方式 | 定时任务 + REST API |

## 2. 功能详情

### 2.1 支持的指数

| 代码 | 名称 |
|---|---|
| 000001 | 上证指数 |
| 399001 | 深证成指 |
| 399006 | 创业板指 |
| 000688 | 科创50 |
| 000300 | 沪深300 |
| 000016 | 上证50 |
| 000905 | 中证500 |
| 000852 | 中证1000 |

### 2.2 数据字段

- 实时行情：当前点位、涨跌幅、涨跌额、成交量、成交额
- 历史数据：OHLCV（日线）

### 2.3 API 端点

- `GET /api/v1/market` — 实时指数行情
- `GET /api/v1/market/history` — 历史 K 线

## 3. 定时任务

| 任务 ID | 时间 | 说明 |
|---|---|---|
| `market_snapshot_midday` | 12:00（工作日） | 午间大盘快照 |
| `market_snapshot_close` | 15:10（工作日） | 收盘大盘快照 |

## 4. 数据表

- `index_snapshot` — 指数快照表
- `index_daily` — 指数日线表

## 5. 前端页面

- `/market` — 大盘总览
- `/market/history` — 历史行情
