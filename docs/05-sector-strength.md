# 板块强度追踪 PRD

## 1. 模块概述

| 属性 | 值 |
|---|---|
| 模块 ID | 05 |
| 模块名称 | 板块强度追踪 |
| 核心功能 | 计算板块连续强势天数、主力净流入等派生指标 |
| 关键文件 | `backend/app/services/sector_strength.py` |
| 触发方式 | 被其他模块调用 |

## 2. 功能详情

### 2.1 强度指标

- **连续强势天数**：板块连续上涨/跑赢大盘的天数
- **平均涨幅**：近 N 日平均涨跌幅
- **累计主力净流入**：近 N 日主力净流入总额
- **强度评分**：综合评分（0-100）

### 2.2 计算逻辑

```
强度评分 = f(连续强势天数, 平均涨幅, 主力净流入, 成交量变化)
```

## 3. 调用方

- `tomorrow_strategy.py` — 明日策略生成
- `sector_analysis.py` — 板块 AI 分析
